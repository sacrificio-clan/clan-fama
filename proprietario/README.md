# Perfil do proprietário

Esta pasta é exclusiva para o perfil especial do proprietário do clã.

- Edite `perfil.js` para alterar o nick ou a FAMA.
- Para atualizar a FAMA, altere somente o valor de `fame`.
- Envie sua foto para esta pasta com o nome exato `foto.png` (PNG recomendado).
- O perfil aparece na Visão Geral e não ocupa um dos 50 slots.
- As informações deste perfil não são carregadas nem salvas no Supabase.
